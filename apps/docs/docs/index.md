Gloups is a health coach for sportspeople, with nutrition, training, sleep and
optional menstrual cycle tracking in its confirmed product scope.

This local documentation site starts the Blume workspace. The repository's
`docs/README.md` remains the index for product decisions, architecture, work
packets and verification records. Product applications are still planned.

Add Markdown or MDX pages beside this file to extend the site. Run
`bun run docs:dev` from the repository root to preview changes, and
`bun run docs:build` to build static files in `apps/docs/dist`.
