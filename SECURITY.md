# Security

The repository is private and documentation only. There is no running product or
security certification in this checkout. See [security/privacy responsibilities](docs/SECURITY-PRIVACY.md).

Report a vulnerability to the maintainers through an existing private channel, or
GitHub private vulnerability reporting if it is enabled for this repository.
Do not put health records, credentials, signed URLs, tokens or private device logs
in public issues, Canny, commits or screenshots. Include a minimal synthetic
reproduction, the affected revision, observed impact and relevant environment.

Do not test against production accounts or change provider/hosting controls as
part of a repository task without authorization for that environment. Keep
incident evidence private and preserve it before cleanup.

The first consumer release does not offer HIPAA BAA or HDS support. The release
must still assess applicable obligations and meet its approved privacy/security
requirements. No framework or document establishes a compliance claim.
