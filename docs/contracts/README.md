# Accepted contracts

No new runtime contract has been accepted or implemented yet. Requirements live
in [CONTRACTS](../CONTRACTS.md); domain proposals belong in their assigned specs.

Accepted contracts record version, approval/revision, producers/consumers, exact
behavior, numeric/time semantics, errors, consent/rights, retry/conflict behavior
and real-boundary acceptance. The integration owner coordinates shared changes.

Historical source contracts are linked from the design draft as evidence. Do
not copy them here as accepted new APIs without review. A client may not infer a
schema from another agent's branch or an ORM entity.
